# Снапшот `echo-2026-10-29`

Результати розділу «Спінове відлуння для годинника» з `fringes/README.md`. `echo.py` прогнано на заморожених checkpoints `pr7-2026-10-28` (Soliton і Pure, seeds 900–902), по одному JSON на модель. `echo_path.py` дає траєкторію класового сигналу по токенах для Soliton seed 900: це картинка до відлуння, а не тест. Це post hoc розвідка. Снапшот не переписують: нові прогони йдуть у новий снапшот. `MANIFEST.json` зберігає SHA-256 і точну команду-виробника кожного файла. Прогнози закомічено до прогонів (`ec377df`). Файли `echo` зробив `echo.py` з цього коміту, а `echo_path` — `echo_path.py` з `ddfcbb3`. `source_commit` у маніфесті — це HEAD на момент заморожування, коли до `echo.py` уже додали `--only` і `--sigmas`. Повний прогін від цього не змінюється, а вибіркова версія на цій машині точно відтворює ті самі клітинки.

У кожному JSON для 11 протоколів (`none24`, `none32`, `none48`, `off24`, `off48`, `echoJ48`, `echoP48`, `echoPJ48`, `rewindJ48`, `rewindP48`, `rewindPJ48`) і 25 значень σ записано:
- `own` — власний readout;
- `lda0` — LDA, навчена при σ = 0 на 2048 послідовностях `echo-cal`;
- `r` і `norm` — перекриття класового сигналу з сигналом при σ = 0 того самого протоколу і його відносна норма;
- `abs0` і `sigma0` — абсолютна норма при σ = 0 і перший нуль r;
- `overlap0` — перекриття сигналів при σ = 0 між протоколами.

```bash
phs-soliton/.venv/bin/python fringes/artifacts/verify.py fringes/artifacts/echo-2026-10-29
```

Скрипт звіряє хеші і запускає `echo.py --selftest` для Soliton і Pure seed 900:
- без імпульсів цикл побітово дає логіти самої моделі (σ = 0 і 0.6);
- G⁻¹G = I;
- один обернений токен і одне перевертання P зсувають логіти.

Далі `echo.py --only none48,echoJ48,echoPJ48,rewindPJ48 --sigmas 0.0,0.6` переграє чотири протоколи для Soliton seed 900. Допуски такі:
- власний readout — у межах однієї біноміальної стандартної похибки з 1024 (щонайменше 3);
- LDA, навчену при σ = 0, — у межах трьох, бо її навчають заново на станах, як оракул у `transfer --full`;
- r і норма — до 0.01, як у законі годинника.

Перед replay скрипт перевіряє, що еталон містить усі 11 протоколів на всій сітці з 25 σ. На машині, де снапшот зроблено, replay точний.

`--bite` готує три підроблені копії:
- копію з переверненим байтом;
- копію з оновленим маніфестом, де r відлуння P + J при σ = 0.6 зсунуто на 0.05, а перемотаний readout при σ = 0 — на 30 із 1024. Ці два рядки мусять упасти, а `none48` і σ = 0 відлуння мусять пройти;
- копію без протоколу `echoJ48`, яку перевірка мусить відхилити ще до replay.
