# Снапшот `decouple-2026-10-29`

Результати розділу «Динамічне розв'язування» з `fringes/README.md`. `decouple.py` прогнано на заморожених checkpoints `pr7-2026-10-28` (Soliton і Pure, seeds 900–902), по одному JSON на модель. Прогнози закомічено до прогонів (`8714aab`), файли зробив `decouple.py` з того самого коміту. `source_commit` у маніфесті — HEAD на момент заморожування, коли до `decouple.py` уже додали `--only` і `--sigmas`. Повний прогін від цього не змінюється, а вибіркова версія на цій машині точно відтворює ті самі клітинки. Це post hoc розвідка. Снапшот не переписують: нові прогони йдуть у новий снапшот. `MANIFEST.json` зберігає SHA-256 і точну команду-виробника кожного файла.

У кожному JSON для рядів CPMG з n = 0, 1, 3, 7, 21, 63 імпульсів P + J при T = 128 і σ = 0, 0.1, …, 1.2 записано:
- `own`, `aware`, `pooled` — власний readout, LDA того самого σ (знає σ) і одна pooled LDA на всі σ (сліпа до σ). Обидві LDA навчено на калібрувальних клітинках того самого n;
- `r`, `norm`, `abs`, `sigma0` — перекриття кінцевого класового сигналу з сигналом при σ = 0, його відносна й абсолютна норма і перший нуль r;
- `trace` — r після кожного токена при σ = 0.3, 0.6, 0.9;
- `anchor0` і `abs0_t` — при σ = 0 перекриття c(t) з c(3) і |c(t)| після кожного токена;
- `pulses` — токени, перед якими стоїть імпульс.

```bash
phs-soliton/.venv/bin/python fringes/artifacts/verify.py fringes/artifacts/decouple-2026-10-29
```

Скрипт звіряє хеші і запускає `decouple.py --selftest` для Soliton і Pure seed 900:
- без імпульсів цикл побітово дає логіти моделі;
- кожен ряд має n імпульсів і нульовий чистий оберт;
- один імпульс зсуває логіти.

Далі `decouple.py --only 0,63 --sigmas 0.0,0.6` переграє ряд без імпульсів і найщільніший ряд для Soliton seed 900. Допуски такі:
- власний readout — у межах однієї біноміальної стандартної похибки з 1024 (щонайменше 3);
- LDA того самого σ — у межах трьох, бо її навчають заново;
- r і норма — до 0.01.

Допуски спираються на `artifacts/drift.py --decouple`. Шум в один ulp float32 на вагах зсуває r щонайбільше на 0.0014, норму — на 0.0005, а десять ulp — норму на 0.0055. Найщільніший ряд не зсувається зовсім, а LDA рухається не більш ніж на 0.09 стандартної похибки. Перед replay скрипт перевіряє, що еталон містить усі шість рядів на всій сітці з 13 σ. На машині, де снапшот зроблено, replay точний.
