# Снапшот `readout-2026-10-28`

Результати розділу «Чесний декодер» з `fringes/README.md`: `readout.py` на заморожених checkpoints `pr7-2026-10-28` (Soliton і Pure, seeds 900–902), по одному JSON на модель. Це post hoc розвідка. Снапшот не переписують: нові прогони йдуть у новий снапшот. `MANIFEST.json` зберігає SHA-256 і точну команду-виробника кожного файла.

```bash
phs-soliton/.venv/bin/python fringes/artifacts/verify.py fringes/artifacts/readout-2026-10-28 --full
```

`--full` звіряє хеші й повторює Soliton seed 900 повністю: калібрувальний і тестовий набори на всіх 25 σ, усі п'ять декодерів. Це займає близько 3 хв. Стани float, тож на іншому CPU допускається розбіжність до 2 послідовностей із 1024 на кожну точність, D і K — до 1e-6. На машині, де снапшот зроблено, розбіжність 0. `--bite` готує дві підроблені копії. У першій перевернуто один байт. У другій точність при σ = 0.70 зсунуто на 3 послідовності, а на місці точності при σ = 0.80 стоїть NaN, і маніфест підправлено під обидві підробки. Перевірка мусить відхилити саме ці два рядки й пропустити контрольний рядок σ = 0.
